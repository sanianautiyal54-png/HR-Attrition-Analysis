# 📊 HR Attrition Analysis Dashboard

## 📌 Project Overview

This project focuses on analyzing **employee attrition using Microsoft Excel and Microsoft Power BI**.

The project uses employee data to identify attrition patterns across different **departments, job roles, and tenure groups**. Microsoft Excel is used for data preparation and analysis, while Power BI is used to create an interactive dashboard and visualize key HR insights.

The main goal is to help HR teams understand employee turnover and make data-driven decisions to improve employee retention.

---

## 🎯 Project Objectives

- Analyze employee attrition using HR data.
- Calculate key HR metrics using Microsoft Excel.
- Prepare and organize data for analysis.
- Create an interactive HR Attrition Dashboard using Power BI.
- Analyze attrition by department.
- Analyze attrition by job role.
- Analyze attrition based on employee tenure.
- Identify areas that may require employee retention strategies.
- Present actionable HR insights through data visualization.

## 📈 Dashboard Analysis

### 1. Attrition Rate

The dashboard displays the overall employee attrition rate as a key performance indicator.

**Overall Attrition Rate: 16.1%**

This provides a high-level view of employee turnover within the organization.

---

### 2. Attrition by Department

The Power BI dashboard includes an **Attrition Rate by Department** visual.

The department-level analysis helps identify which departments have relatively higher employee attrition.

This can help HR investigate factors such as:

- Workload
- Management practices
- Employee satisfaction
- Career-growth opportunities
- Working environment

---

### 3. Attrition by Job Role

The dashboard includes an **Attrition Rate by Job Role** visual.

This analysis helps identify job roles where employee turnover may be relatively high.

High-attrition roles can be reviewed for possible issues related to:

- Career development
- Role clarity
- Training
- Recognition
- Compensation
- Employee satisfaction

---

### 4. Attrition by Tenure

The dashboard also analyzes employee attrition based on tenure.

This helps HR understand whether employees are more likely to leave during particular stages of their employment.

Particular attention can be given to **early-tenure employees** if the dashboard shows elevated attrition in this group.

Possible actions include:

- Improved onboarding
- Regular employee check-ins
- Mentoring
- Early-career development programs

## 💼 Business Recommendations

### 1. Focus on High-Attrition Departments

HR should prioritize departments with higher attrition rates and investigate:

- Workload
- Management practices
- Employee satisfaction
- Career opportunities

### 2. Review High-Attrition Job Roles

High-attrition job roles should be reviewed individually.

Possible retention strategies include:

- Career development
- Training
- Role clarity
- Recognition
- Compensation review

### 3. Strengthen Employee Onboarding

If early-tenure employees show higher attrition, the organization can improve:

- Onboarding programs
- Mentoring
- Regular check-ins
- Early-career support

### 4. Conduct Employee Engagement Surveys

Regular employee engagement surveys can help identify recurring causes of employee dissatisfaction before they result in turnover.

### 5. Monitor Attrition Using Power BI

The Power BI dashboard can be used regularly to monitor:

- Attrition rate
- Department-wise attrition
- Job-role attrition
- Tenure-based attrition

This allows HR to evaluate the effectiveness of retention initiatives over time.
